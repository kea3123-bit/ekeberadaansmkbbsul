# eKeberadaan web-only architecture

The active migration target is now **GitHub Pages + Google Apps Script + Google Sheets**.

Vercel is not required for this branch.

Frontend: GitHub Pages
Backend/runtime: existing Google Apps Script Web App
Database: existing Google Sheet
Timezone: Asia/Kuala_Lumpur

The Pages frontend is generated from the existing Apps Script UI files so the current layout and client logic remain the source of truth.
